    조건 해석

    📌 주요 활용 대상

    • 소상공인·예비 창업자: 주 고객층과 성수기에 맞춘 실행 시기 탐색

    • 제주빅데이터센터 이용자: 코드 없는 데이터 탐색과 시각화

    • 행정·관광 실무자: 출처와 산출 근거가 있는 보고서 초안 작성

    Gemini API 키 설정

    키는 이 PC의 프로젝트 폴더에 있는 .env 파일에만 저장되며, 저장 후에는 화면에 다시 표시되지 않습니다. 키가 없으면 규칙 기반 모드로 실행됩니다. 무료 등급에서는 입력한 질문이 Google 제품 개선에 활용될 수 있으므로 개인정보나 민감정보를 입력하지 마세요.
