# 데이터 활용 명세

## 최신 실제 원본 CSV 취득 (2026-11-19)

사용자 승인으로 `src/hub_export.py`를 명시 실행해 두 API의 조회 범위(2000-01~2026-11) 내 전 페이지를 취득했습니다. 월간 19,573행(실제 2016-09~2018-12), 요일별 1,050행(실제 2016-09~2017-11)입니다. 결과는 `data/exports/jeju_20261119/`에 원본 영문 필드·값 그대로 보존하며 API 총건수·CSV 재읽기 일치를 확인했습니다. 자세한 출처·해시·한계는 [수집 결과](csv-export.md)를 참고하세요.

이후 사용자 “연결해” 요청으로 원본을 앱에 연결했습니다. 월간은 19,573행을 보존하고 기본 집계 시 내국인관광객을 선택합니다. 요일별은 내국인관광객 525행만 앱에 연결하고 중국인관광객 525행은 원본에 보존합니다. marketType의 “테마, 업종” 매핑은 기존 인터페이스의 호환 처리일 뿐 독립 테마 데이터가 아니며 화면·보고서·모델 메타데이터에 이를 안내합니다. 상세 내역은 [연결 기록](real-data-connection.md)에 있습니다. 원본 파일과 키는 공개 GitHub에 포함하지 않습니다.

## 3. 앱용 로컬 CSV 연결 및 전처리 흐름

1. `src/activate_data.py`가 이미 수집된 원본 CSV와 `receipt.json`을 읽어 SHA-256, 필드, 건수, 값 형식을 대조합니다. 서버 시작 시 데이터 API를 자동 호출하지 않습니다.
2. 월간 데이터의 업종·연령·성별 등이 `전체`인 합계 행은 중복 집계를 막기 위해 제외합니다.
3. 요일별 원본에서 내국인관광객만 선택하고, 필드명을 변환해 `data/raw/card_monthly.csv`, `data/raw/card_weekday.csv`로 저장합니다. 원본은 수정하지 않고 연결 기록을 `source_manifest.json`에 남깁니다.
4. `src/data_pipeline.py`가 필수 컬럼을 확인하고 숫자와 날짜 형식을 통일합니다.
5. 결측 행과 중복 행을 제외하고, 음수 값은 경고로 기록합니다. 처리 건수는 화면의 `Agent 설계 원칙`에서 확인할 수 있습니다.
6. 연령대와 성별 표기를 표준화하고(`20 미만`, `20대미만`은 `20대 미만`으로 통합), 지구를 시군구에 연결합니다.

## 4. 분석 흐름

| 도구 | 사용 데이터 | 계산 내용 |
| --- | --- | --- |
| `analyze_trend` | 주 데이터 | 월별 이용금액, 1인당 금액, 전년 동월 대비 증감률 |
| `rank_segments` | 주 데이터 | 지역·업종·연령대·성별 순위, 비중, 증가율 |
| `weekday_pattern` | 보조 데이터 | 요일별 비중, 주말·평일 비중, 건당 금액 |
| `verify_result` | 주·보조 데이터 | 원본 재계산, 조건 일치, 비중 합계, 표본 크기 |
| `build_report` | 분석 결과 | 검증된 결과로 보고서 구성, 근거 없는 수치 차단 |

## 5. 합성 샘플 데이터

`data/raw/`에 실제 데이터가 없으면 `src/sample_data.py`가 만든 합성 샘플 데이터로 실행합니다. 합성 데이터는 기능 시연용이며 실제 제주 통계가 아닙니다. 화면과 보고서에 이 사실을 표시합니다.

## 6. 개인정보

활용 데이터는 지역·업종·연령대·성별 단위로 집계된 통계이며 개인 식별 항목을 포함하지 않습니다.

## 7. 외부 데이터 및 오픈소스

필수 데이터 외의 외부 데이터는 사용하지 않았습니다. 오픈소스 목록은 `docs/disclosure.md`에 있습니다.
