# 실제 CSV 웹 앱 연결 기록

작성일: 2026-11-19. 사용자 요청: “연결해”. 원본 취득과 별개로 로컬 연결·분석을 검증했습니다.

## 1. 구현 목표

이미 받은 실제 CSV를 주 FastAPI 웹 앱의 계산에 사용합니다. 추가 데이터 API·생성형 AI 호출 없이 연결했고 정적 데모와 Streamlit 보조 앱은 변경하지 않았습니다.

## 2. 서비스 제안

주 앱 실행: `run.bat` 또는 `.venv\Scripts\python.exe -m src.server`. 주소는 http://127.0.0.1:8501 입니다. 상단에 실제 CSV와 월간 2016-09~2018-12 / 요일 2016-09~2017-11이 표시됩니다. Gemini 키가 없으면 실제 CSV를 이용하는 규칙 기반 분석으로 동작합니다.

“서귀포시 30대 여성 식음료 소비 추세 알려줘”를 입력하면 성별·연령대·지역·업종·내국인관광객 조건을 적용합니다. 과거 자료를 현재 소비 동향처럼 설명하지 않으며, 과거 최고 소비 월을 향후 행사 일정으로 제안하지 않도록 보완했습니다.

## 3. Agent 개발 구성

`src/activate_data.py`: 원본 해시·스키마 확인 → 모집단 선택·컬럼 변환 → 임시 CSV로 앱 전처리 검증 → 앱 CSV 및 연결 기록 저장. 원본과 기존 앱 파일은 덮어쓰지 않습니다.

`src/server.py`: 시작 시 데이터 API 자동 수집을 제거했습니다. 상태 API에 데이터 방식, 월간·요일별 건수와 기간을 제공합니다. 질문 처리·도구·보고서의 기존 구조는 유지했습니다.

`src/rule_engine.py`, `src/tools/analysis.py`: 업종과 동일한 테마 호환값은 업종 순위로 표시하고, “상업지”처럼 시군구가 특정되지 않는 지구를 임의로 제주시로 연결하지 않습니다. `src/prompts.py`와 도구 메타데이터에도 실제 집계 단위와 모집단을 명시했습니다. 원본에 있는 “문화/레저” 표기도 질문 동의어에 반영했습니다.

## 4. 데이터 활용 계획

| 연결 파일 | 행 수 | 내용 |
| --- | ---: | --- |
| data/raw/card_monthly.csv | 19,573 | 내국인관광객 9,807행·제주도민 9,766행 보존. 기본 분석은 내국인관광객 |
| data/raw/card_weekday.csv | 525 | 내국인관광객만 사용. 중국인관광객 525행은 원본에 보존 |
| data/raw/source_manifest.json | 해당 없음 | 원본·가공 파일 해시, 건수, 적용 조건, 기간 기록 |

월간의 합계 “전체” 행 제거 규칙을 적용했으나 이번 원본에서 제외된 행은 0건입니다. 성별·연령대·지역·업종 값은 보존하고 표시용 성별과 연령대 표기만 기존 전처리로 정규화합니다. 테마 컬럼은 기존 인터페이스 호환을 위해 업종 값을 복사한 것이며 독립 데이터로 설명하지 않습니다.

요일 자료는 월·요일 집계이며 개별 거래 날짜가 아닙니다. 특정 성별·연령대의 선호 요일을 알 수 없습니다. 누적 이용자수는 고유 인원수가 아니며 이용금액/이용자수 비율을 개인 여행 예산으로 해석하지 않습니다.

## 5. 개발·탑재 계획

```powershell
.venv\Scripts\python.exe -m src.activate_data data/exports/jeju_20261119
.venv\Scripts\python.exe scripts/verify_real_csv.py
.venv\Scripts\python.exe -m src.server
```

이 PC에서는 연결이 끝났으므로 서버만 실행하면 됩니다. 기존 앱 CSV가 있으면 연결기는 중단합니다. 서버가 이미 실행 중이었다면 재시작해야 합니다. GitHub에는 코드·문서만 올리고 실제 CSV·로컬 연결 기록·키는 제외합니다. 다른 PC에서는 원본 또는 적법하게 전달받은 앱용 CSV를 별도로 준비해야 합니다. 파일 재배포 이용조건과 최종 ZIP 검증·제출은 별도입니다.

## 6. 검증·한계·센터 활용

- 외부 네트워크 차단 회귀 테스트: 168 passed. 가짜 CSV·키로 실패 처리, 원본 변조 거부, 덮어쓰기 차단, 성별/모집단 필터, 서버 시작 시 무호출을 확인했습니다.
- 실제 CSV 독립 합산: 2018년 서귀포시·30대·여성·식음료·내국인관광객 이용금액의 API 원값 합계 9,259,306,060이 분석 코드 값과 일치했습니다. 상업지·내국인관광객·요일 자료 전체 수록 기간 합계 51,049,651,381도 일치했습니다.
- 실제 CSV 웹 API 질문 5건: 서귀포시 30대 여성 식음료, 제주시 20대 여성 카페(식음료로 확장 안내), 제주시 구도심 요일, 상업지 요일, 업종 증가율. 모두 보고서 생성, 각 4·4·8·8·8개 검증에서 실패·경고 0건입니다.
- 브라우저에서 실제 CSV 상태와 여성·30대 조건, 보고서·차트의 생성 및 검증 4/4 표시를 확인했습니다. 자동화 도구의 버튼 클릭이 제한 시간 내 완료되지 않아 폼 제출로 기능을 검증했습니다.
- 실제 CSV 검증 명령은 외부 네트워크를 차단하고 LLM 키를 해당 프로세스에서만 비웁니다. 설정 파일은 변경하지 않았습니다. 기존 합성 30문항 평가는 `sample_only=True`로 격리하여 실데이터 성능이라고 재표기하지 않습니다.

기존 별도 작업의 실제 Gemini 예시 2건 성공은 합성 데이터 기준이며 이번 실제 CSV+규칙 경로 검증과 다릅니다. 실제 CSV+Gemini 평가, 현재 시점의 대표성, 센터 PC 성능은 이번에 검증하지 않았습니다.
