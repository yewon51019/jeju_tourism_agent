# 제주 관광 소비 인사이트 Agent 실행 매뉴얼

## 실행 방법

1. Python 3.14를 설치합니다.
2. 프로젝트 폴더의 `run.bat`을 더블클릭합니다.
3. 브라우저에서 `http://127.0.0.1:8501`이 열리면 질문을 입력합니다.

## Claude API 키 설정

1. 화면 오른쪽 위의 `API 키 입력`을 누릅니다.
2. `sk-ant-`로 시작하는 키를 입력하고 `확인 후 저장`을 누릅니다.
3. 상단 표시가 `Claude 사용`으로 바뀌면 설정이 끝납니다.

키는 프로젝트 폴더의 `.env` 파일에 저장되며 화면에 다시 표시되지 않습니다. 키가 없거나 Claude API 호출이 실패하면 규칙 기반 분석으로 실행됩니다.

## 데이터 준비

실제 데이터를 사용하려면 아래 두 파일을 `data/raw/` 폴더에 넣고 앱을 다시 실행합니다. 파일이 없으면 합성 샘플 데이터로 실행되며 화면에 그 사실이 표시됩니다.

| 파일명 | 데이터 | 필수 컬럼 |
| --- | --- | --- |
| `card_monthly.csv` | 월간 내국인관광객 카드 사용 정보 | 기준연월, 테마, 업종, 시군구, 지역구분, 관광객구분, 연령대, 성별, 이용자수, 이용금액 |
| `card_weekday.csv` | 관광지 및 상업지구 요일별 카드 데이터 | 날짜, 지구, 요일, 이용자수, 이용횟수, 이용금액 |

컬럼명이 다르면 `src/data_pipeline.py`의 `MONTHLY_COLUMNS`, `WEEKDAY_COLUMNS`에 별칭을 추가합니다. 지구와 시군구의 연결은 같은 파일의 `DISTRICT_REGION`에서 수정합니다.

## 예시 질문

- 서귀포시에서 30대 관광객을 대상으로 식음료 프로모션을 하려면 언제가 좋을까?
- 제주시 20대 여성 관광객의 카페·디저트 소비 추세는 어때?
- 중문관광단지의 요일별 소비 패턴을 주말과 평일로 비교해줘
- 최근 1년 제주 전 지역에서 전년 대비 소비 증가율이 가장 높은 테마는?

## 오류 및 제약사항

| 증상 | 조치 |
| --- | --- |
| 필수 컬럼이 없다는 오류 | CSV 컬럼명을 확인하고 별칭을 추가합니다. |
| API 키 형식 또는 인증 오류 | 키를 다시 발급하거나 입력값을 확인합니다. |
| 규칙 기반 분석으로 전환됨 | 인터넷 연결, API 사용 한도, 키 상태를 확인합니다. |
| 패키지 설치 실패 | 인터넷 연결과 Python 버전을 확인합니다. |

- 월간 데이터는 시군구 단위이며 읍면동, 시간대, 외국인 관광객은 분석하지 않습니다.
- 요일별 데이터에는 업종, 연령, 성별이 없어 해당 지역 전체 소비 기준으로 해석합니다.
- 실행 제안은 참고 자료이며 매출 효과를 보장하지 않습니다.
