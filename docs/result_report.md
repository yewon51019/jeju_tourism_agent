# 결과 설명자료

> 이 문서의 실행 결과는 **합성 샘플 데이터**로 계산했으며 실제 제주 관광 통계가 아닙니다.


## 1. 문제 정의

제주 관광 소비 데이터는 공개되어 있지만, 분석 경험이 없는 소상공인과 센터 이용자는 데이터를 고르고 집계해 의사결정에 활용하기 어렵습니다. 본 Agent는 자연어 질문만으로 소비 시기, 고객층, 지역, 업종을 분석하고 근거가 있는 보고서를 제공합니다.

## 2. Agent 구조

| 단계 | 담당 | 내용 |
| --- | --- | --- |
| 질문 해석 | Claude | 지역, 업종, 고객층, 기간, 분석 목적 해석 |
| 조건 확인 | Claude | 조건이 모호하면 사용자에게 선택지 제시 |
| 분석 계획 | Claude | 데이터와 도구 선택 |
| 집계·분석 | Python | 추세, 순위, 비중, 증감률, 요일 패턴 계산 |
| 결과 검증 | Python | 원본 재계산, 조건 일치, 비중 합계, 표본 크기 점검 |
| 보고서 생성 | Claude + Python | 검증된 수치로 보고서 작성, 근거 없는 수치 차단 |

Claude API를 사용할 수 없으면 규칙 기반 분석으로 전환해 같은 계산과 검증을 수행합니다.

## 3. 주요 기능

- 자연어 질의와 조건 되묻기
- 월별 추세, 순위, 전년 대비 증감률, 요일별 패턴 분석
- 원본 데이터 재계산 검증과 판단 로그
- 차트, 수치 근거, 실행 제안이 포함된 보고서
- 요약 복사와 PDF 저장

## 4. 실행 결과

아래 결과는 규칙 기반 분석 경로로 실행했습니다.

### 사례 1. 서귀포시에서 30대 관광객을 대상으로 식음료 프로모션을 하려면 언제가 좋을까?

**서귀포시 30대 관광객 식음료 소비 분석 및 프로모션 적기 제안**

서귀포시 30대 관광객 식음료 소비는 2026년 8월에 가장 많아 분석 기간 이용금액의 9.7%를 차지합니다. 상위 3개월(2026년 8월, 2025년 10월, 2026년 5월)의 비중은 28.8%입니다. 서귀포시 요일별 데이터 기준으로 토·금요일에 주간 소비의 36.9%가 집중되고, 주말(토·일) 비중은 34.9%, 평일(월~금) 비중은 65.1%입니다.

- 분석 기간 최고 소비 시기: 2026년 8월 (분석 기간 이용금액의 9.7% · 33.9억 원)
- 소비 집중 요일: 토·금요일 (36.9%) (최저 화요일 11.3% · 서귀포시 기준)
- 1인당 평균 이용금액: 54,463원 (전년 동기 대비 총 이용금액 +6.5%)
- 검증 결과: 8건 중 8건 통과, 경고 0건

### 사례 2. 제주시 20대 여성 관광객의 카페·디저트 소비 추세는 어때?

**제주시 20대 여성 관광객 카페·디저트 소비 분석 리포트**

- 분석 기간 최고 소비 시기: 2026년 8월 (분석 기간 이용금액의 10.5% · 5.5억 원)

- 검증 결과: 4건 중 4건 통과, 경고 0건

### 사례 3. 제주시 구도심의 요일별 소비 패턴을 주말과 평일로 비교해줘

**제주시 요일별 소비 패턴 분석**

제주시 요일별 데이터 기준으로 토·금요일에 주간 소비의 36.8%가 집중되고, 주말(토·일) 비중은 34.8%, 평일(월~금) 비중은 65.2%입니다. 제주시 관광객 소비는 2026년 8월에 가장 많아 분석 기간 이용금액의 10.1%를 차지합니다. 상위 3개월(2026년 8월, 2025년 10월, 2026년 7월)의 비중은 29.0%입니다.

- 분석 기간 최고 소비 시기: 2026년 8월 (분석 기간 이용금액의 10.1% · 488.9억 원)
- 소비 집중 요일: 토·금요일 (36.8%) (최저 화요일 11.2% · 제주시 기준)
- 1인당 평균 이용금액: 54,192원 (전년 동기 대비 총 이용금액 +5.4%)
- 검증 결과: 8건 중 8건 통과, 경고 0건

### 사례 4. 최근 1년 제주 전 지역에서 전년 대비 소비 증가율이 가장 높은 테마는?

**최근 12개월 테마별 소비 증가율 분석**

전년 동기 대비 증가율이 가장 높은 테마는 문화·레저(+14.4%)이고, 가장 낮은 테마는 쇼핑(-1.6%)입니다. 제주 전체 관광객 소비는 2026년 8월에 가장 많아 분석 기간 이용금액의 10.4%를 차지합니다. 상위 3개월(2026년 8월, 2026년 5월, 2026년 7월)의 비중은 29.8%입니다.

- 전년 대비 증가율 1위 테마: 문화·레저 (+14.4%) (최저: 쇼핑 (-1.6%))
- 분석 기간 최고 소비 시기: 2026년 8월 (분석 기간 이용금액의 10.4% · 97.1억 원)
- 1인당 평균 이용금액: 54,255원 (전년 동기 대비 총 이용금액 +14.4%)
- 검증 결과: 8건 중 8건 통과, 경고 0건

## 5. 검증 방법 및 결과

- 데이터: 합성 샘플 데이터 (실제 통계 아님) (2024-01 ~ 2026-08)
- 측정 대상: 규칙 기반 분석 경로. Claude API 경로는 이 평가에 포함되지 않습니다.
- 평가 질문은 규칙을 만든 참가자가 직접 작성했으므로 처음 보는 질문에서는 정확도가 더 낮을 수 있습니다.

| 지표 | 결과 | 기획서 목표 |
| --- | --- | --- |
| 질문 조건 추출 정확도 | 30/30 (100.0%) | 90% 이상 |
| 분석 유형·도구 선택 정확도 | 30/30 (100.0%) | 90% 이상 |
| 조건 되묻기 판단 정확도 | 30/30 (100.0%) | 별도 목표 없음 |
| 데이터 한계 안내 정확도 | 30/30 (100.0%) | 별도 목표 없음 |
| 보고서 생성 성공률 | 26/26 (100.0%) | 별도 목표 없음 |
| 원본 재계산 검증 통과율 | 26/26 (100.0%) | 100% |


검증 항목은 원본 재계산, 조건 일치, 비중 합계, 표본 크기입니다. 자동 테스트는 `tests/` 폴더에 있습니다.

## 6. 한계

- 필수 데이터의 수록 기간이 2016~2018년이어서 최근 소비 동향을 반영하지 않습니다.
- 카드 이용 내역만 분석하며 현금 등 다른 결제 수단은 포함하지 않습니다.
- 요일별 데이터에는 업종, 연령, 성별이 없고 월간 데이터와 수록 기간이 다릅니다.
- 분석 결과는 상관관계에 기반하며 실행 제안의 매출 효과를 보장하지 않습니다.
- 위 평가는 규칙 기반 경로를 측정한 것이며 Claude API 경로의 성능은 포함하지 않습니다.

## 7. 센터 활용 방안

- 방문 이용자의 셀프 분석 도구와 소상공인 상담 자료로 활용합니다.
- 판단 로그를 데이터 분석 입문 교육 자료로 활용합니다.
- 데이터와 Tool을 추가해 교통, 환경 등 다른 분야로 확장합니다.
