# 실제 원본 CSV 수집 결과

작성일: 2026-11-19. 이 기록은 실제 API 수집이며 합성 데모·모의 테스트·LLM 성능 평가와 구분합니다.

## 1. 구현 목표

사용자의 “이제 실제 csv로 만드는 작업해” 요청에 따라 두 데이터 API의 원본 응답을 CSV로 보존했습니다. 기존 앱과 원본 기획서는 변경하지 않았습니다.

## 2. 서비스 제안

| 파일 | 행 수(헤더 제외) | 실제 수록 기간 | 내용 |
| --- | ---: | --- | --- |
| data/exports/jeju_20261119/monthly_597.csv | 19,573 | 2016-09~2018-12, 28개월 | 지역·업종·성별·연령대·내국인관광객/제주도민 |
| data/exports/jeju_20261119/weekday_608.csv | 1,050 | 2016-09~2017-11, 15개월 | 지구·요일·내국인관광객/중국인관광객 |

인코딩은 UTF-8 BOM으로, 엑셀에서 한글을 읽을 수 있습니다. API 필드명을 유지했으며 월간 `gender`가 성별, `ageGroup`이 연령대입니다. 기준연월은 `dtYearMonth`이며 일별 거래일이 아닙니다. 성별·연령대별 선호 요일은 두 자료로 직접 산출할 수 없습니다.

독립적인 PowerShell CSV 재읽기에서도 건수·필드 수·해시가 일치했습니다. 월간은 내국인관광객 9,807행·제주도민 9,766행, 요일별은 내국인관광객 525행·중국인관광객 525행입니다. 이는 이용자 수가 아니라 집계 행 수입니다.

## 3. Agent 개발 구성

수집기 [src/hub_export.py](../src/hub_export.py)는 명시적으로 실행할 때만 동작합니다. 페이지별 조회 → 총건수·스키마·값 검증 → 임시 폴더 저장 → 전체 파일 재읽기 대조 → 결과 폴더 확정 순서입니다. 기존 결과 폴더는 덮어쓰지 않으며, 실패 시 부분 결과를 완료 폴더로 남기지 않습니다. 실제 API 요청은 월간 196회·요일별 11회, 합계 207회입니다. 자동 반복 수집·LLM 호출은 하지 않았습니다.

## 4. 데이터 활용 계획

조회 조건은 `startDate=200001`, `endDate=202611`, 페이지당 100행이며 관광객 구분 등의 필터는 적용하지 않았습니다. 이 범위 안에서 서버가 알린 총건수와 모든 페이지의 수신 건수를 대조했습니다. 조회 범위 밖 또는 이후 갱신 데이터까지 확보했다는 의미는 아닙니다.

- 원본 필드·값을 그대로 보존하며, 합계 행 제거·업종의 테마 복제·관광객 필터를 적용하지 않았습니다. 실제 이번 응답의 업종 목록에는 “전체”가 없었습니다.
- 597번 11개 필드: sido, sigungu, cityGubun, marketType, userType, ageGroup, gender, dtYearMonth, userCount, useCount, useCost.
- 608번 7개 필드: districtType, userType, dtYearMonth, dtWeek, userCount, useCount, useCost.
- 연령대 `20 미만`과 `20대미만`은 원본 표기를 유지했습니다. 분석용 변환 시 동의 표기 통합이 필요합니다.
- 관광객과 도민, 내국인과 중국인을 혼합한 합계를 관광객 전체 통계처럼 해석하지 않습니다. 지구 이름의 “중국인 주요 관광지”와 실제 이용자 `userType`은 서로 다른 분류입니다.
- 이용자수 합계는 전체 기간의 고유 인원수가 아닙니다. 금액은 단위 변환 없이 API 값을 보존했으며 이용조건·집계 정의·재배포 가능 범위는 추가 확인 대상입니다.

## 5. 개발·탑재 계획

```powershell
.venv\Scripts\python.exe -m src.hub_export --start 200001 --end 202611 --output data/exports/jeju_20261119
```

프로젝트 루트에서 실행합니다. 키는 환경변수 또는 로컬 `.env`의 `JEJU_HUB_PROJECT_KEY`에서 읽고 출력하지 않습니다. 폴더가 이미 있으면 새 출력 경로를 지정해야 합니다. 데이터별 최대 400회, 재시도 없이 오류 시 중단합니다. 서버·권한·조회 한도에 따라 재실행 시 결과가 달라질 수 있습니다.

원본 CSV와 `receipt.json`은 로컬 `data/exports/`에만 저장되며 Git에서 제외됩니다. 앱이 읽는 `data/raw/card_monthly.csv`, `card_weekday.csv`로 이름만 바꾸면 안 됩니다. 원본의 영문 필드·모집단을 검증해 별도 가공하는 단계가 필요합니다. 이번 작업에서 앱의 합성 데이터 경로를 실제 분석으로 전환하지 않았습니다.
