# 사용자 매뉴얼

## 1. 설치 및 실행

| 항목 | 내용 |
| --- | --- |
| 운영체제 | Windows 10 이상 |
| Python | 3.12 이상 (개발·테스트 환경 3.14) |
| 센터 PC 사양 | Intel Core i7-8700, RAM 32GB. GPU는 사용하지 않음 |
| 인터넷 | 패키지 설치, Gemini API, 데이터 다운로드에 필요 |

1. ZIP을 `C:\jeju_tourism_agent`처럼 경로가 짧은 폴더에 풀고 `run.bat`을 더블클릭합니다.
2. 브라우저에서 `http://127.0.0.1:8501`이 열립니다. 열리지 않으면 주소를 직접 입력합니다.
3. 종료할 때는 실행 창을 닫습니다.

## 2. API 키 설정

API 키는 프로젝트 폴더의 `.env` 파일 한 곳에만 입력합니다. 소스 코드는 수정하지 않습니다. `.env`는 `run.bat`을 처음 실행할 때 `.env.example`을 복사해 자동으로 만들어집니다.

| 키 | 입력할 파일 | 입력할 줄 | 키를 읽는 코드 |
| --- | --- | --- | --- |
| Gemini API 키 | `.env` | `GEMINI_API_KEY=발급받은 키` | `src/agent.py`의 `GeminiAgent` |
| 제주데이터허브 프로젝트 키 | `.env` | `JEJU_HUB_PROJECT_KEY=발급받은 키` | 명시적으로 실행하는 `src/hub_export.py` |

### 2.1 Gemini API 키 (외부 AI API, 무료 등급)

평가 시에는 `EVALUATION_KEY.md`의 평가용 키를 사용합니다. 직접 발급하는 순서는 다음과 같습니다.

1. [Google AI Studio의 API 키 페이지](https://aistudio.google.com/apikey)에 Google 계정으로 로그인하고 약관에 동의합니다. 만 18세 이상만 사용할 수 있습니다.
2. `Create API key`를 눌러 키를 만듭니다. 무료로 사용하려면 결제를 연결하지 않은 프로젝트를 선택합니다.
3. 만들어진 키를 복사합니다.

키는 다음 두 방법 중 하나로 입력합니다.

- **화면 입력:** 화면 오른쪽 위 `API 키 입력`을 누르고 키를 붙여넣은 뒤 `확인 후 저장`을 누릅니다. 키가 `.env`에 자동으로 저장됩니다.
- **파일 입력:** `.env`를 메모장으로 열어 `GEMINI_API_KEY=` 뒤에 키를 붙여넣고 저장한 다음 `run.bat`을 다시 실행합니다.

상단 표시가 `Gemini 사용`으로 바뀌면 키가 설정된 것입니다. 예시 질문을 실행한 뒤 보고서의 실행 모드가 `Gemini Agent`로 표시되면 Gemini API 호출이 정상입니다. `규칙 기반 분석`으로 표시되면 키와 사용 한도를 확인합니다. 저장된 키는 화면에 다시 표시되지 않습니다.

- 기본 모델은 `gemini-3.5-flash-lite`이며 `.env`의 `GEMINI_MODEL`에서 바꿀 수 있습니다.
- 평가용 키는 참가자가 준비한 무료 등급 키이며 결제가 연결되어 있지 않아 평가 중 비용이 발생하지 않습니다.
- 무료 등급의 분당·일일 한도는 프로젝트와 모델별로 다르며 [AI Studio 사용량 페이지](https://aistudio.google.com/rate-limit)에서 확인합니다. 일일 한도는 미국 태평양 시간 자정에 초기화됩니다.
- 질문 1건을 분석할 때 Gemini API를 여러 번 호출합니다. 한도를 넘으면 잠시 재시도한 뒤 규칙 기반 분석으로 전환합니다.
- 무료 등급에서는 입력 내용과 응답이 Google 제품 개선에 활용되고 사람이 검토할 수 있습니다. 질문에 개인정보, 민감정보, 기밀정보를 입력하지 않습니다.
- 평가용 키는 평가 기간 종료 후 삭제·폐기합니다.

### 2.2 제주데이터허브 프로젝트 키 (데이터 API)

실제 프로젝트 키는 제출물에 포함하지 않았습니다. 데이터를 직접 내려받으려면 아래 순서로 발급합니다.

1. [제주데이터허브](https://jejudatahub.net)에 회원가입하고 로그인합니다.
2. `마이페이지 > 프로젝트 관리 > 프로젝트 만들기`에서 프로젝트를 만듭니다.
3. 아래 두 데이터 페이지에서 각각 `프로젝트 담기`를 눌러 만든 프로젝트에 추가합니다.
   - [내국인 관광객 지역, 업종, 성별, 연령대별 카드 이용 데이터](https://jejudatahub.net/data/view/data/597)
   - [관광지 및 상업지구 요일별 카드 데이터](https://jejudatahub.net/data/view/data/608)
4. `마이페이지 > 프로젝트 관리 > 해당 프로젝트`에서 프로젝트 키를 복사합니다.
5. `.env`를 메모장으로 열어 `JEJU_HUB_PROJECT_KEY=` 뒤에 프로젝트 키를 붙여넣고 저장합니다.
6. 신규 수집이 필요할 때만 2.3절의 원본 수집 명령을 실행합니다. 이미 원본 CSV가 있으면 API 키 없이 아래 연결 명령만 실행합니다.
7. `run.bat` 실행 후 화면 상단에 `실제 CSV`와 월간·요일별 기간이 표시되는지 확인합니다.

서버 시작 시 데이터 API를 호출하지 않습니다. `data/raw/`에 두 CSV가 있으면 해당 파일을 사용하며, 둘 다 없으면 합성 샘플로 표시됩니다. 하나만 있으면 오류를 표시합니다. 원본 연결 명령은 다음과 같으며 기존 앱 CSV를 덮어쓰지 않습니다. 이미 연결된 이 PC에서는 재실행하지 않아도 됩니다.

```powershell
.venv\Scripts\python.exe -m src.activate_data data/exports/jeju_20261119
```

현재 월간 19,573행(관광객·도민 구분 보존), 요일별 525행(내국인관광객만)이 연결되었습니다. 추가 API 호출은 없습니다. 상세 검증은 [실제 연결 기록](real-data-connection.md)을 참고하세요.

### 2.3 API 호출 코드 위치

원본 CSV를 값 변환 없이 별도로 보존하려면 다음 명령을 사용합니다. 이 명령은 앱을 실행하지 않으며 원본을 앱용 CSV로 전환하지도 않습니다.

```powershell
.venv\Scripts\python.exe -m src.hub_export --start 200001 --end 202611 --output data/exports/jeju_20261119
```

기존 폴더는 덮어쓰지 않으므로 재실행 시 새 출력 폴더를 지정합니다. `monthly_597.csv`, `weekday_608.csv`, `receipt.json`이 생성됩니다. 엑셀에서는 UTF-8 CSV로 열 수 있습니다. 2026-11-19 결과는 월간 19,573행, 요일별 1,050행이며 두 파일 모두 관광객 구분을 보존합니다. 원본을 `card_monthly.csv` 등으로 이름만 바꾸지 마세요. 상세 형식·주의사항은 [원본 수집 결과](csv-export.md)에 있습니다.

| 기능 | 파일 | 함수 |
| --- | --- | --- |
| Gemini API 클라이언트 생성 | `src/settings.py` | `create_client` |
| 사용자 문장을 Gemini에 보내 JSON 형식으로 해석 | `src/agent.py` | `GeminiAgent._interpret` |
| 응답 JSON 형식 정의와 검증 | `src/interpreter.py` | `interpretation_schema`, `parse_interpretation` |
| Gemini의 도구 호출과 분석 진행 | `src/agent.py` | `GeminiAgent._create`, `GeminiAgent.run` |
| 보고서 형식과 수치 검증 | `src/agent.py`, `src/interpreter.py` | `_reject_report`, `ReportDraft` |
| 제주데이터허브 Open API 호출 | `src/hub_api.py` | `fetch_all`, `download`, `ensure_hub_data` |
| 명시적 원본 CSV 내보내기 | `src/hub_export.py` | `collect`, `save_csv`, `export` |
| 저장한 원본의 로컬 연결 | `src/activate_data.py` | `read_verified`, `activate` |
| 프롬프트 | `src/prompts.py` | `INTERPRET_PROMPT`, `SYSTEM_PROMPT` |

## 3. 사용 방법

1. 질문을 입력하거나 예시 질문을 누릅니다.
2. 조건이 모호하면 화면에 표시되는 지역·업종·연령대를 선택합니다.
3. 분석 파이프라인에서 진행 단계와 판단 로그를 확인합니다.
4. 보고서의 핵심 요약, 차트, 수치 근거, 실행 제안, 유의사항을 확인합니다.
5. `요약 복사` 또는 `PDF 저장·인쇄`로 결과를 저장합니다.

### 예시 질문

- 서귀포시에서 30대 관광객을 대상으로 식음료 프로모션을 하려면 언제가 좋을까?
- 제주시 20대 여성 관광객의 카페·디저트 소비 추세는 어때?
- 제주시 구도심의 요일별 소비 패턴을 주말과 평일로 비교해줘
- 최근 1년 제주 전 지역에서 전년 대비 소비 증가율이 가장 높은 테마는?

## 4. 오류 해결

| 증상 | 원인 | 조치 |
| --- | --- | --- |
| Python 3.12 이상이 필요하다는 안내 | Python 미설치 또는 낮은 버전 | Python을 설치한 뒤 다시 실행 |
| 지원하지 않는 Python 버전이라는 안내 | 기존 `.venv`의 버전이 낮음 | `.venv` 폴더를 삭제한 뒤 다시 실행 |
| 폴더 경로가 너무 길다는 안내 | Windows 경로 길이 제한 | `C:\jeju_tourism_agent`처럼 짧은 경로로 이동 |
| 패키지 설치 실패 | 인터넷 연결 문제 | 연결 확인 후 다시 실행 |
| API 키 형식 또는 인증 오류 | 잘못되었거나 폐기된 키 | 키를 다시 확인 |
| 규칙 기반 분석으로 전환됨 | 키 없음, API 장애 | 키와 인터넷 연결 확인 |
| Gemini 무료 사용량 한도에 도달했다는 안내 | 무료 등급의 분당 또는 일일 한도 초과 | 1분 뒤 다시 실행하고, 계속되면 한도 초기화 후 실행 |
| 프로젝트 키를 확인하라는 안내 | 키 오류 또는 프로젝트 담기 누락 | 안내에 표시된 데이터 번호(597번, 608번)를 2.2절의 3~4번에 따라 다시 확인 |
| 합성 샘플로 실행된다는 안내 | 앱용 로컬 CSV 두 파일 없음 | 원본을 준비한 뒤 2.2절 연결 명령 실행, 서버 재시작 |
| 일일 호출 한도 초과 | 데이터별 일일 1,000회 초과 | 다음 날 다시 실행 |
| 필수 컬럼이 없다는 오류 | CSV 형식이 다름 | `download_data.bat`으로 다시 다운로드 |

## 5. 제약사항

- 제주데이터허브의 월간 카드 데이터 수록 기간은 2016년 9월~2018년 12월, 요일별 카드 데이터는 2016년 9월~2017년 11월입니다. 최근 소비 동향은 반영하지 않습니다.
- 월간 데이터는 시군구와 도심·읍면 단위까지 제공되며 개별 읍면동은 분석하지 않습니다.
- 카페·디저트 등 세부 업종은 제공되지 않아 식음료 업종으로 분석합니다.
- 요일별 데이터에는 업종, 연령, 성별이 없어 해당 지구 전체 소비 기준으로 해석합니다.
- 시간대, 현금 결제는 분석하지 않습니다.
- 실행 제안은 참고 자료이며 매출 효과를 보장하지 않습니다.
