# 평가셋

questions.json은 단순 추세, 집단 순위·비중, 요일 집계, 조건 누락, 미지원 질문을 포함하는 30개 질문입니다.

현재 자동 테스트는 **오프라인 규칙형 해석기**의 예상 조건·도구 선택과 일치하는지 확인합니다. 이 결과를 Claude의 질문 해석 정확도나 기획서의 90% 목표 달성 수치로 제출하면 안 됩니다.

실제 Claude 평가 시 동일 질문을 실행하고 기대 조건·도구 선택과 비교해야 합니다. 모호한 질문은 되묻기, 미지원 질문은 거절·범위 설명을 정답으로 봅니다. API Key와 비용이 필요하므로 현재 작업에서는 실제 호출 평가를 하지 않았습니다.

계산 검증은 tests/test_tools.py의 독립 fixture와 원본 재계산 경로로 별도 확인합니다. 판단 로그는 실행 단계별 tool/input/output을 기록합니다.
